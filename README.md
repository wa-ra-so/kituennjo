# 近くの喫煙所マップ

位置情報を使って、近くの喫煙所をマップ上のピンで確認できるWebアプリです。スマホのブラウザでそのまま使えます。

## 機能

- 現在地を地図上に表示（青い丸）
- 喫煙所を🚬ピンで表示し、タップすると名称・住所・現在地からの距離・Googleマップでのルート案内を表示
- 現在地から近い順にリスト表示、表示範囲（500m/1km/3km/5km/すべて）を切り替え可能
- 地図の中心に喫煙所を追加登録（端末のlocalStorageに保存。他の人とは共有されません）

## データについて

`data/smoking-spots.json` に初期データとして、全国の主要駅・空港周辺の喫煙所を収録しています（北海道: 札幌、東北: 仙台、関東: 東京・新宿・渋谷・池袋・品川・上野・横浜、中部: 名古屋、関西: 京都・大阪、中国: 広島、四国: 高松、九州: 博多、沖縄: 那覇空港）。各スポットはJR東日本メディアや自治体公式サイトなど個別の公開情報源を典拠にしており、`source`フィールドに出典URLを記載しています。ただし座標は出典記事の記述から推定した概算位置であり、現地の正確なGPS実測ではありません。実際に利用する際は、現地で確認した正確な位置に更新するか、アプリ内の「＋ この地図の中心に喫煙所を追加」から自分で登録してください。

より詳細・網羅的な喫煙所情報が必要な場合は、JTの公式サービス「CLUB JT」（https://www.clubjt.jp/place/spot/）もあわせてご利用ください。

## 使い方（ローカルで動かす）

ブラウザの `fetch` を使ってJSONを読み込むため、`index.html` をファイルとして直接開く（`file://`）と正しく動作しません。簡易サーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 公開する場合

GitHub Pagesなどの静的ホスティングにそのまま配置すれば、スマホからもアクセスできます。位置情報の取得にはHTTPS（またはlocalhost）が必要です。

## 構成

- `index.html` / `style.css` / `app.js` — アプリ本体
- `data/smoking-spots.json` — 喫煙所の初期データ
- `vendor/leaflet/` — 地図描画ライブラリ Leaflet（CDNに依存せずローカル同梱）
