# 近くの喫煙所マップ

位置情報を使って、近くの喫煙所をマップ上のピンで確認できるWebアプリです。スマホのブラウザでそのまま使えます。

## 機能

- 現在地を地図上に表示（青い丸）
- 喫煙所を🚬ピンで表示し、タップすると名称・住所・現在地からの距離・Googleマップでのルート案内を表示
- 現在地から近い順にリスト表示、表示範囲（500m/1km/3km/5km/すべて）を切り替え可能
- 地図の中心に喫煙所を追加登録（端末のlocalStorageに保存。他の人とは共有されません）

## データについて

`data/smoking-spots.json` に初期データとして、47都道府県すべての県庁所在地・主要駅周辺の喫煙所を1件以上収録しています（合計106件）。

関東圏は重点的に拡充しており、1都6県すべてで主要駅を個別にカバーしています。

| 都県 | 収録件数 | 主な収録駅 |
|---|---|---|
| 東京 | 23 | 東京・新宿・渋谷・池袋・品川・上野・新橋・秋葉原・北千住・立川・吉祥寺・町田 |
| 千葉 | 15 | 千葉・船橋・西船橋・柏・松戸・津田沼・市川・海浜幕張・舞浜・成田空港 |
| 神奈川 | 8 | 横浜・川崎・武蔵小杉・藤沢・桜木町 |
| 埼玉 | 4 | 大宮・川口・所沢・川越 |
| 茨城 | 2 | 水戸・つくば |
| 栃木 | 2 | 宇都宮・小山 |
| 群馬 | 2 | 前橋・高崎 |

各スポットには`sources`フィールドに出典URLを配列で記載しており、可能な限り2件以上の独立した情報源（自治体公式サイト、JR東日本メディア、駅構内情報サイトなど）で内容を突き合わせています。ただし座標は出典記事の記述から推定した概算位置であり、現地の正確なGPS実測ではありません。一部（`type`が「概算位置」のもの）は具体的な施設名の一次情報が見つからず、駅周辺の座標のみを暫定的に登録しています。実際に利用する際は、現地で確認した正確な位置に更新するか、アプリ内の「＋ この地図の中心に喫煙所を追加」から自分で登録してください。

なお、柏駅前・新潟駅万代口・山形駅・奈良駅など、近年の受動喫煙対策で路上指定喫煙所が撤去された場所もあります。そうしたエリアは代替となる屋内施設の喫煙所を収録するか、`address`にその旨を注記しています。

より詳細・網羅的な喫煙所情報が必要な場合は、JTの公式サービス「CLUB JT」（https://www.clubjt.jp/place/spot/）もあわせてご利用ください。

## 使い方（ローカルで動かす）

ブラウザの `fetch` を使ってJSONを読み込むため、`index.html` をファイルとして直接開く（`file://`）と正しく動作しません。簡易サーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 公開する場合

GitHub Pagesなどの静的ホスティングにそのまま配置すれば、スマホからもアクセスできます。位置情報の取得にはHTTPS（またはlocalhost）が必要です。

## 構成

- `index.html` / `style.css` / `app.js` — アプリ本体
- `data/smoking-spots.json` — 喫煙所の初期データ
- `vendor/leaflet/` — 地図描画ライブラリ Leaflet（CDNに依存せずローカル同梱）
